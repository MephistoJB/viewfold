# HACS publishing notes

Viewfold can be installed today as a HACS custom repository. Inclusion in HACS’s default catalog is a separate, human-reviewed process and is not implied by this repository.

After the project has established users and meets the current HACS inclusion criteria, a maintainer can personally:

1. Re-read the current [HACS publishing requirements](https://www.hacs.xyz/docs/publish/include/).
2. Confirm repository description, topics, releases, brand assets, issue tracking, and HACS validation all pass.
3. Open the HACS default-repository submission flow as a human and review every submitted field.

No automated workflow in this repository opens external issues or pull requests.
