# Code of conduct

## Our standards

Project spaces should be welcoming, respectful, and focused on constructive collaboration. Examples of positive participation include using inclusive language, accepting feedback gracefully, respecting different experiences, and prioritizing the community’s interests.

Harassment, discriminatory language, personal attacks, deliberate intimidation, publication of private information, and sustained disruption are unacceptable.

## Scope

This policy applies in repository issues, pull requests, discussions, and other spaces where someone represents the project.

## Enforcement

Report conduct concerns privately through the repository owner’s GitHub profile or, when confidentiality is important, through a private security advisory marked as a conduct report. Maintainers may edit or remove inappropriate contributions and may temporarily or permanently restrict participation. Reports will be handled as confidentially as practical.
